# 1.0.0

Typed module factories preserve the author's concrete React type. The package check
compiles a strict installed consumer, including expected failures for unsupported
commands, snapshot mutation and invalid factories. Runtime behavior is unchanged.

First independent packaging of the existing Amplifier shell SDK and controls
authoring example. The SDK runtime and host interface 1.0 retain their Unified behavior;
the declaration refinement preserves existing explicit-return factory calls. The installable package includes a standalone example
that uses host React and public SDK imports only.

Unified host validation and recovery contracts remain authoritative. Package
qualification covers installation and bundling; host acceptance is a separate
DTU check. The initial candidate preserves the exact component bytes already
qualified against the Unified production-browser fixture.
