# 1.0.0

First independent packaging of the existing Amplifier shell SDK and controls
authoring example. The SDK runtime, host interface 1.0 and declarations retain
their Unified behavior. The installable package includes a standalone example
that uses host React and public SDK imports only.

Unified host validation and recovery contracts remain authoritative. Package
qualification covers installation and bundling; host acceptance is a separate
DTU check. The initial candidate preserves the exact component bytes already
qualified against the Unified production-browser fixture.
